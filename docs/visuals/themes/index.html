Theme options

The same request and the same Valio view in five themes. Only colours, type and borders change; the layout is untouched. Each theme is a CSS override (docs/visuals/themes/themes.py).

A · Current: navy bar, orange accent

B · Valio white: white bar, one Valio blue, bold titles

C · Navy night: dark Valio navy, white type, bright blue

D · Outside review: off-white, navy text, teal actions

E · Nordic paper: warm paper, black ink, one Valio blue, square and bold
