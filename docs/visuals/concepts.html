Concept B · Narrowing funnel

From 17,546 products to one, with 3 live API calls

Every step is a check with a reason. Most of the narrowing happens on Valio’s static data; the live price and stock APIs are only asked about the last 16.

Why it matters

A keyword agent would have stopped at step 2 and ordered the first hit: in file order, a chocolate milk drink.

Lactose-free is checked against nutrition data, not the name: 195 products failed.

Valio’s guidance: “query the APIs only when you have narrowed down the products”. 3 calls, 589 ms.
