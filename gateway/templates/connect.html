Connect your own agent

Any agent goes through the same six checks and the same audit trail.

Add the MCP server

For Claude, ChatGPT and other AI agents.

claude mcp add --transport http valio https://valio.psavela.com/mcp \
  --header "Authorization: Bearer <agent token>"

The token is the agent's, not the sign-in password. Each buyer has its own.

2

What the agent can do

Seven tools. Approving is not one of them: only a person can.

preplan_requestPurchase or inquiry, catalog preview and explicit authority boundaries; never orders
get_mandateThe buyer's rules, signed by the buyer
search_productsSearch the catalog, no live calls
check_price_availabilityLive price and stock, up to 20 products
request_offerA signed fixed price for 15 minutes
place_orderPlaced, sent to a person, or stopped
get_orderStatus and the decision record

Start with the preplanner

Choose Purchase or Inquiry explicitly.

Call preplan_request through MCP, or POST /v1/preplan with your buyer-bound agent token. Both accept the same fields and return the request purpose, catalog matches, buyer hard rules, delegated agent limits and next steps. Neither creates an offer, reservation or order.

{"purpose":"inquiry","mandate_id":"mnd_hotel_helsinki","product":"milk","attributes":["FREE_FROM_LACTOSE"]}

For purchase, also provide a positive quantity, unit (litres, kg or pieces), and deliver_by (YYYY-MM-DD). Optional allergies tighten the preview. Use the typed API schema for accepted values.

Inquiry: use search and price tools to answer; do not place an order. Purchase: preserve the buyer's requirements, obtain a signed offer, then explicitly place it. Selecting Purchase never bypasses a rule. Selecting Inquiry here does not revoke the token's separate order capability.

Buyer limits and agent authority are different

Buyer hard rules come from the registered buyer mandate and are enforced by the gateway: exceeding them blocks the order. Agent authority is the buyer's delegated per-order and 24-hour spending allowance: exceeding it requires a person. Built-in and external agents share the allowance for that buyer; it is not per token.

For the Hotel mandate, the baseline is €5,000 hard cap, €500 autonomous per order and €1,500 autonomous in 24 hours. Read the current selected mandate; other buyers differ. A signed week plan may pre-authorize spend, but cannot remove hard rules.

Current limits of the integration: private outside-agent budgets and request-only budget caps are not sealed into the external quote API. Preview-only allergy additions are not automatically carried into low-level quotes either. If a tighter requirement is not in the registered mandate, stop for the buyer rather than dropping it. The response reports these gaps; a matching product is not permission to purchase.
