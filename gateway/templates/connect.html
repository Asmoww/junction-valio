Open interface

Bring your own agent

Any purchasing agent can work with the gateway on open standards: MCP for AI agents, OpenAPI for everything else, and signed offers anyone can verify. Every channel goes through the same mandate check and audit trail.

MCP server

Streamable HTTP at https://valio.psavela.com/mcp with a bearer token: the agent token below, not the sign-in password. For example in Claude Code:

claude mcp add --transport http valio https://valio.psavela.com/mcp \
  --header "Authorization: Bearer <agent token>"

Trust

Offers are Ed25519-signed JWS. Verify them without trusting the channel they came through.

/.well-known/jwks.json
  • Prices are fixed catalog prices, never negotiated
  • Live prices are re-checked before committing
  • Supplier text is untrusted data and is scanned
  • Every decision is in a hash-chained audit log

Peppol orders

Every placed order is also a Peppol BIS Ordering 3 document (UBL 2.1 Order), so it drops into any Peppol-capable ERP or access point. Checked against the official UBL 2.1 schema; party IDs are demo values.

GET /v1/orders/{order_id}/peppol.xml

Mandate as a credential

The buyer signs its mandate as a W3C Verifiable Credential (vc+jwt, EdDSA), with its key published as a did:web. The gateway enforces only a mandate whose signature checks out: an edited mandate blocks every order until the buyer signs it again.

GET  /v1/mandates/{mandate_id}/credential
POST /v1/mandates/verify     (open to anyone)
GET  /buyers/{buyer}/did.json
